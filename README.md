# Balance — личные финансы без облачной базы

## Вход и публикация

Приложение полностью работает в браузере. Neon, DATABASE_URL, PASSWORD_HASH **не нужны**. DATABASE_URL и LOCAL_DATA не используются. SESSION_SECRET создаётся один раз при настройке деплоя для подписи сессии. Пароль установлен по запросу владельца; начальная выписка и цели зашифрованы в lib/initial-vault.json.

- Локально: `npm install`, затем `npm run dev`, откройте http://localhost:3000.
- Проверки: `npm test`, `npm run build`.
- Vercel: Framework Other, Build `npm run build`, Output `dist`. Исходная копия дополнительно зашифрована серверным VAULT_KEY, который хранится только в Vercel. Для собственного нового деплоя настройте VAULT_KEY для этой копии и установите SESSION_SECRET (случайная строка из `openssl rand -hex 32`); для текущего проекта это уже настроено.
- Свой домен: Settings → Domains, добавьте домен и установите предложенные Vercel DNS-записи.

## Где сохраняются данные

Все изменения сохраняются в localStorage текущего браузера **зашифрованными** (AES-256-GCM, ключ из пароля через PBKDF2-SHA256, 310000 итераций). Ключ находится только в памяти вкладки; при обновлении страницы потребуется снова войти. Неправильный пароль не расшифрует данные.

Автоматической синхронизации между устройствами нет. «Скачать копию» сохраняет зашифрованный JSON; «Восстановить» переносит его на другой компьютер или телефон. Восстановление заменяет текущие данные после подтверждения. Очистка хранилища браузера удалит локальные изменения, поэтому сохраняйте копии. Начальная выписка останется в приложении. Слабый пароль допускает подбор скачанного зашифрованного файла; установлен именно пароль, выбранный владельцем.

## Возможности

Система целей: предложение → свадьба → Mercedes SLK, три зарплатных поступления, распределение по целям, дневной лимит, бюджет жизни, обязательный кредитный платёж и план погашения Т-Банка. Сроки не рассчитываются при неизвестном бюджете предыдущей цели. Сценарии свадьбы — лето 2027/2028, без инфляции и доходности.

Overview, операции и их редактирование, аналитика по категориям и месяцам, регулярные списания, cashflow, savings rate, бюджеты и возвраты. Извлечены 956 строк выписки; технические и собственные переводы не считаются доходом. Внешние поступления не автоматически считаются зарплатой. Сентябрь неполный, средние — за июль и август. Отчёт находится в REPORT.private.md.

## Приватные файлы

Исходные JSON и отчёт исключены из Git и Vercel. Начальная копия находится только в серверной функции и выдаётся после проверки пароля. Без входа сервер возвращает 401. Публичная сборка не содержит исходную или зашифрованную выписку. Повторно создавать её при каждом деплое не нужно. Для отдельного переимпорта есть `scripts/make-vault.js`, которому нужны приватные JSON и VAULT_PASSWORD. Не добавляйте исходные приватные файлы в Git.

Сервер только проверяет пароль и выдаёт начальную зашифрованную копию. Данные пользователя хранятся в браузере, внешняя база не используется.
